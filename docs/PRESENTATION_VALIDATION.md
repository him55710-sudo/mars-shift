# Standalone presentation

`public/downloads/MARS-SHIFT-7-slides.pptx` is the same seven-slide story as the web briefing, packaged as a downloadable presentation. It contains four embedded real-data/application images, a native editable comparison table on slide 4, source citations in speaker notes and explicit simulation/AI disclosures.

The final exported file was imported with the first-party Artifact Tool, all seven slides were rendered, and each final slide was visually reviewed. Package integrity, geometry, slide count, font policy and native-table checks passed. Native PowerPoint execution was not tested. The file's hash and concise validation record are in `public/data/presentation-validation.json`.

The local Spaces editing session was unavailable, so the permitted standalone PPTX workflow was used. The unused blank draft Page was moved to Trash. No presentation is claimed to have been edited or tested in a native PowerPoint application.
