# 심사 기준 평가와 개선 — v15

평가일: 2026-11-15. 대상: v14(c01cc9b)를 보존한 독립 v15 작업본. 실제 심사위원을 모집한 평가가 아닌, 공식 기준을 적용한 내부 비판적 검토다. 실험을 새로 꾸미거나 기존 결과를 덮어쓰지 않았다.

## 기준과 판단

[NASA Space Apps 공식 심사 안내](https://www.spaceappschallenge.org/resources/judging-awards-guide/)의 Impact, Creativity, Validity, Relevance, Presentation을 각각 1–5점으로 평가했다. 공개 안내에서 수치 가중치는 확인되지 않아 가중 총점·수상 확률을 계산하지 않았다. 제공된 서울 행사 자료 `2026- D-Day.pptx` 46번 슬라이드도 같은 다섯 항목이다. 문서는 평가 근거이며 코드 실행/제출 지시로 취급하지 않았다.

| 항목 | v14 검토 | v15 내부 재평가 | 근거와 남은 감점 |
|---|---:|---:|---|
| Impact 영향력 | 3/5 | 3/5 | 국소 위험에서 다음 행동과 복귀를 함께 제공하는 목적은 명확하다. 실제 사용자 효용 및 현장 피해 감소는 아직 측정되지 않았다. |
| Creativity 창의성 | 3/5 | 3/5 | 불확실성·자원·지형·HUD의 통합은 차별점이다. A*, IMM, 분류를 발명한 것은 아니며 최신 동급 시스템 대비 우월성을 입증하지 않았다. |

UI 개선만으로 과학 점수를 올리지 않았다. 실제 심사 점수는 심사위원의 재량과 전체 출품작에 따라 달라진다.

## 가장 큰 과학적 문제

1. **미터 단위 계산과 실측 미터 정확도가 혼동될 수 있다.** 실측 기반 거리 재구성은 1개 사건, 4개 위치, 3개 미래 비교다. 3.04 m는 논문 근사 재구성에 대한 오차이며 독립 정답에 대한 1 m 정확도가 아니다. 이미지 클립 3개, 합성 192개, 과거 합성 조합 7,200개도 독립 실측 사건 수로 바꾸면 안 된다.
2. **최신 대피 개선은 작다.** 동일 36개 조건에서 Guarded 평균 접촉 2.480초, Static 2.761초, 이전 통합 2.482초다. 감소율은 각각 10.190%, 0.064%. 이전 통합 대비 1개 개선·35개 동률·악화 0개이며 무접촉 27/36, 복귀 실패 0/36은 모두 같다. Adaptive 단독은 2.490초로 이전 통합보다 나쁘다. 완전정보 기준선도 2.466초이므로 현재 후보 행동과 조건에서 남은 차이는 작다. 더 쉬운 조건을 골라 큰 향상처럼 보이면 안 된다.
3. **예측 평균 향상이 모든 상황의 향상은 아니다.** 합성 확인 192개에서 RMSE 31.79→27.05 m지만 47개는 악화했다. 명목 95% 영역의 실제 포함률은 91.8%다. 이를 보정된 95% 안전영역이라고 표시하면 안 된다.
4. **모래 후보 회피와 모래 탐지 정확도는 다르다.** 같은 12개 경로의 후보 버퍼 셀 합계 185→0은 마스크 회피를 검증한다. 전체 경로 가능 조건은 18/26→12/26으로 감소한다. 독립 지반 실패 정답은 0개이며, 텍스처 분류만으로 침하 확률을 주장할 수 없다.

## 다음 반복의 승격 조건

새 실험 전에 목표·허용 악화·관측 누락·접촉·반응지연·여유반경·자원·최소 유의 효과를 고정한다. 현재 확인 세트를 재사용한 튜닝은 개발 결과로 분리한다. 새 사건 단위 추적 검증과 새 공간 구역 단위 모래 검증 없이 일반화 향상을 선언하지 않는다.

- **국소 예측:** 독립 거리/방위/시간 정답을 확보하고 2·5·10·20초 미래의 RMSE, 편향, p95, 영역 포함률을 보고한다. 연속 프레임을 독립 사건으로 취급하지 않는다. 필요한 사건 수는 파일 수가 아니라 선행 변동성과 요구 오차폭으로 산정한다.
- **대피:** 같은 조건에서 정적/이동만/통합/완전정보를 비교한다. 연속 구간 접촉, 최소 이격, 경로 길이, 접촉시간, 무접촉률, 복귀 실패, 불필요 HOLD와 끝까지의 처리 지연을 기록한다. 평균만 개선되고 복귀 실패가 늘어난 모델은 자동 승격하지 않는다.
- **모래:** 별도 지역의 loose/firm 정답과 등록 오차를 확보해 precision/recall·경계오차를 측정한다. 역학 정답 전에는 후보 지도로만 제공한다. 누락 데이터와 부적합 목적지를 조용히 안전한 곳으로 바꾸지 않는다.
- **시연:** 관측/시뮬레이션 범위를 사용자가 설명할 수 있는지, 경고 후 올바른 다음 행동을 읽는지 측정한다. 우주복 손상이나 부상률 모델을 새로 추가하는 것은 이 작업의 목적이 아니다.

관련 선행 대피 연구 검토는 기존 `public/data/hazards/vortex-v10/process-review.md`를 보존했다. 재현성·동일 조건·정보 지연·실패 분석의 원칙을 채택하며, 지구 재난의 보행/유체 계수를 그대로 화성 정답으로 전용하지 않는다.

## 제출 적합성

[공식 제출 안내](https://www.spaceappschallenge.org/resources/project-submission-guide/)에 맞춰 현재 데모는 영문 7장, 프로젝트는 별도 `/review` 동선이다. 공개 링크의 비로그인 접근과 실제 제출 상태는 이번 로컬 작업에서 검증하지 않았다. 이전 PPT는 최신 기능을 설명하지 않으므로 현재 데모 대신 사용하지 않는다. AI 보조와 NASA/오픈소스 출처를 영문 방법 문서에 표시했다.

## 검증 기록

- Vitest: 45개 파일, 329개 테스트 통과(기존 320개 + 신규 9개).
- TypeScript, Vite 빌드, Navcam 사진 자산 패키징, 증거 일치 검사 통과. 프로덕션 서버에서 6개 원본 결과의 HTTP 응답 바이트 해시도 일치했다.
- 추가 번역 후 빌드와 병행한 검사에서는 기존 `eva.test.ts` 한 사례가 5초 제한으로 실패했다. 제한/검사를 바꾸지 않고 빌드 완료 후 전체를 단독 재실행해 45개 파일 329개가 모두 통과했다. 실패 로그도 보존했다.
- v13 동결 예측 재현: development, selection, confirmation, observed의 결정론적 결과가 일치했고 원본은 변경되지 않았다. 이 명령은 대피 경로 실험을 새로 실행한 것이 아니다.
- Chrome 실제 UI: 7개 슬라이드 이동/끝 버튼, 같은 5개 모델 표, 관측 재생 링크, 390×844 모바일, 모래 이동 후 언어 전환, 20분 예산 HOLD, 헬멧 속도 변경 시 기존 지표 철회 확인. 모바일 슬라이드 버튼 넘침을 수정했고 짧은 데스크톱 화면에도 비교표 전체가 보이도록 조정했다.
- 로컬 최종 빌드: `http://127.0.0.1:5210/review` / `/briefing`. 외부 배포·제출은 하지 않았다.
- v14 독립 임시 재현: 동결 입력 15개 해시와 130개 case/arm 경로·지표 일치. 머신 의존 시간값은 재현 판정에서 제외. 기존 증거 파일은 그대로다.

현재 결론: **계산과 설명을 검토할 수 있는 연구 시제품**이다. 실측 현장 정확도나 큰 추가 대피 효과를 이미 입증한 제품이라고 평가할 근거는 부족하다. 다음 과학적 개선의 병목은 더 화려한 HUD가 아니라 독립 정답과 새로운 사건/지역 검증이다.
