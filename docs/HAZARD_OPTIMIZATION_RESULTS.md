전체 유형/사건 데이터는 `v3-evaluation.json`, `v3-episodes.csv/json`에 보존했다.

## 낮은 성능의 원인과 변경

1. **장기 불확실성의 과도한 적용.** 기존 충돌 함수는 구간 전체에 마지막 시점의
   가장 큰 반경·공분산을 적용했다. 특히 30초 HOLD 검사에서 먼 미래의 넓은 영역이
   초기 시각에도 적용돼 가능한 행동을 거부했다. 보수적인 검사 자체는 오류가
   아니지만, 최적화에 그대로 쓰면서 과도한 정지로 연결됐다.
2. **이미 위험에 들어가면 탈출도 거부.** 모든 간선에 무접촉을 요구하므로 출발점이
   위험 안에 있으면 모든 이동이 실패했고, 실행기는 제자리에 남았다.
3. **짧은 후보와 끝점 정지.** 약 10m 좌우 후보에 도착한 뒤 30초까지 정지해야 했다.
   계속 이동하면 벗어날 수 있는 경우도 실패했다. 고정 HOLD 비용 16과 이동·지반
   비용의 비교도 불필요한 정지를 유도했다.
4. **방향 변화의 영구 이상치화.** Kalman innovation gate가 진짜 급선회 관측을
   계속 거부하면서 오래된 방향을 유지하고 센서 단절처럼 처리했다.
5. **복귀를 너무 늦게 고려.** 움직임이 가능한 동안 복귀 여유를 늘리기보다,
   예산 제약이 실패한 뒤 후보를 모두 거부하는 경우가 있었다.

개선 모듈 `hazard-mpc.ts`는 기존 지형 A*와 보행 시간 모델을 재사용한 **후보 궤적
기반 receding-horizon 제어**다. 16방향 × 두 거리, 목적지·기지, 정지와 0/4/8초 대기를
비교한다. 각 경로를 30초까지 시간화하고, 첫 2초만 실행한 뒤 다시 계산한다.
5m 격자점 사이에서는 실제 연속 위치를 보존한다. 지형 통과 금지는 유지한다.

0.5초 중간점에서 위치·반경·불확실성을 평가한다. 비용에는 시간별 노출 대리값,
명목 접촉 시간, 침투 깊이, 지반 지수, 거리, 목표까지 거리, 자원 결손이 들어간다.
반경 주변 logistic 함수는 **가정한 위험 점수**이며 보정된 확률이 아니다.
노출 가중치 35와 지반 가중치 1.5는 개발 자료에서 선택했다. 정답 궤적은 평가기에만 있다.
완전 회피 후보가 없더라도 지형상 가능한 최소 노출 후보를 실행하고
`EXPOSURE_MINIMIZING`으로 명시한다. 이를 ‘안전 경로’라고 표시하지 않는다.

복귀 여유가 두 계획 구간보다 작으면 기지 복귀를 우선한다. 2초 실행 뒤 복귀
예산을 만족하는 후보가 존재하면 그 집합 안에서 선택한다. 이미 예산이 부족한
경우에도 이동을 없애지 않고 결손을 표시하며 최소화한다.

연속된 두 관측이 새로운 움직임을 뒷받침하면 추적기를 재획득한다. 단일 이상치는
방향을 바꾸지 못한다. 60m/s 상한은 관측된 최고 속도라는 주장이 아닌 명시한
그럴듯함 검사다. 센서 누락은 최대 16초까지 불확실성이 커지는 예측으로 이어가고
`SENSOR GAP`을 표시한다. 이후에는 안내를 중단한다. 위치 등록 불량은 계속 차단한다.

## 과적합 방지와 실험 이력

- 기존 101–132 실험은 진단 자료로만 취급하고 `v1/`에 원 결과를 보존했다.
- v2 개발 2001–2024에서 설정 선택 후, 새 4001–4048을 평가했다. 576회 결과는
  정적 대비 39.06% 감소였고 급반전 추적 실패가 남았다. `v2-*`로 보존했다.
- 최종 개발은 별도 3001–3024에서 재획득·센서 누락 처리만 비교했다. 마지막
  6001–6070은 설정 동결 뒤 한 번 평가했다. stop/start와 반경 진동도 추가했다.
- `HAZARD_V2_PROTOCOL.md`, `HAZARD_V3_PROTOCOL.md`를 실험 전에 작성했고,
  선택 파일에 SHA-256을 기록했다. 최종 결과 확인 후 계산 설정을 수정하지 않았다.
- 첫 v2 개발 시 생성기의 기지 좌표가 정수가 아닌 결함을 발견했다. 검증 세트를
  열기 전에 중단·수정하고 개발을 다시 실행했다. 회귀 테스트를 추가했다.
- 비교 모델은 동일 지형·시드·보행·센서·자원과 동일 평가기를 쓴다. 새 어려운
  유형에서는 기존 Dynamic도 정적보다 나빴으며 이 결과 역시 그대로 보고한다.
- 자원 입력은 같지만 정적/Dynamic은 복귀 예산을 계획의 강제 제약으로 적용하지
  않는다. 따라서 복귀율 개선은 추적·경로·자원 정책을 합친 시스템 전체의 차이다.
  불확실성 처리만의 순수 효과나 동일 제약 최적화의 우월성으로 해석하지 않는다.

불필요 HOLD 지표는 다음 30초의 정적 목적지 경로가 정답 먼지 영역과 만나지 않는
정지 시간이다. 복귀를 위해 기지에 머무르는 행동도 포함할 수 있으므로 완벽한
‘불필요함’ 분류가 아니다. 복귀 가능성은 정적 지형·자원에 대한 조건부 판정이다.
노출은 독립 평가기의 0.25초 중간점 적분이며 연속 시간의 정확한 접촉 적분은 아니다.

## 실제 발생한 폭풍 데이터와 별도 백테스트

[MDAD v1](https://doi.org/10.7910/DVN/F8R2JX)의 **실제 관측 14,974건**을 내려받았다.
NASA MOC/MARCI 일별 모자이크에서 연구자가 식별한 중심·면적·시간·사건 연결이다.
원 CSV 2,380,661 bytes를 배포 메타데이터와 대조하고 SHA-256을 저장했다. CC0 1.0.
결측 3,168건, 신뢰도 75 미만 3,131건, 합류·분리 ID 501건을 순서대로 제외했다.
남은 8,174행 중 같은 화성 연도/관측 하위 기간/사건에서 3개 이상 관측이 있는
509개 시계열(1,859행)을 구성했다. 하위 기간마다 Sol 번호가 리셋되므로 경계를
가로질러 이어 붙이지 않았다. 관측 간격이 맞지 않는 예측 원점 173건도 제외했다.

MY24–29의 414개 예측으로 오차 크기를 산정하고 MY30의 131개로 감쇠·크기 성장·
관측창을 선택했다. MY31–32의 **85개 사건, 123개 다음 Sol 예측**은 분리 평가했다.
선택된 모델은 관측 이동 속도의 0.5배를 구면 위에서 외삽하고 크기는 유지했다.
성장률 외삽은 검증 자료에서 이득이 없어 채택하지 않았다.

| 실제 일별 폭풍 예측 | Persistence | 감쇠 이류 |
|---|---:|---:|
| 중심 MAE | 672.49km | **557.97km** |
| 중심 RMSE | 1,029.89km | **922.17km** |
| 반경 MAE | 157.24km | 157.24km |
| 동일 면적 원의 IoU | 0.291 | **0.331** |

중심 MAE는 17.03% 감소했다. 사건별 평균 차이의 bootstrap 95% 구간은
[−179.45, −25.21]km다. 훈련 잔차 95백분위 중심 오차 1,334.69km를 적용했을 때
테스트 포함률은 93.50%였다. **오차가 여전히 커 정밀 지상 대피 방향용으로는 부족하다.**
원형 IoU는 실제 경계 IoU가 아니다. 일별 모자이크도 순간 동시 관측이 아니며,
사건 발생·소멸·합류·분리는 예측하지 않는다.

[MDAD v1.1](https://doi.org/10.5281/zenodo.7480334)의 MY31 관측 경계 파일도
공개 MD5와 대조해 확보했다. 10개 역사 재생 사건의 61개 관측 경계를 보존했다.
다만 최종 지리 정합성 검사에서 **31개에 ±90도를 벗어난 위도**가 있었고,
**53개는 v1 중심이 경계의 위·경도 범위 밖**이었다. 두 기본 검사를 모두 통과한
것은 1개뿐이며 이것도 버전 간 정합성을 증명하지 못한다. 공식 배포 예제는
NetCDF 마스크를 읽지만 이 CSV의 좌표 차이를 설명하지 않았다. 임의의 위도
오프셋을 추측해 보정하지 않고, 원좌표와 검사 결과를 보존한 채 **61개 경계
오버레이를 모두 보류**했다. UI에도 보류 사유를 표시한다. 지역 예측과 백테스트는
검증한 v1 중심·면적을 사용하므로 영향을 받지 않는다. 동일 면적 원을 실제 윤곽으로
주장하지 않는다. 경계 데이터는 Battalio et al., CC BY 4.0이다.
실제 km/Sol 폭풍을 m/s 사건으로 축소해서 로컬 시뮬레이션 성과로 세지 않는다.

## XR와 실시간 사용

실시간 Worker가 동결된 모델을 실행한다. XR·Mission Control은 같은 revision과
경로를 사용한다. 이미 먼지 안에 있으면 민트 경로를 유지하고 황색
`EXPOSURE REDUCTION · NOT CLEAR`로 표시한다. 후보별 예상 접촉 시간도 제공한다.
역사적 지역 폭풍 화면은 과거 관측만 예측기에 전달한다. 다음 관측을 공개하는
체크박스는 비교 표시만 바꾸며 예측 입력은 바꾸지 않는다.

지역 예측 범위가 Jezero를 포함할 경우 `Rehearse regional RETURN in XR`로 기지를
목표로 하는 복귀 리허설을 실행한다. 이것은 과거 경보를 현재 데모에 적용하는
명시적인 훈련 모드다. 0.6m/s로 1시간 걸어도 2.16km이므로 수백 km 폭풍을 보행으로
벗어난다고 안내하지 않는다. 실시간 현장 센서 공급과 지역 대기장 동화는 아직 없다.

## 연구 근거

Exa로 3개 관점의 17개 후보와 데이터 다운로드 후속 5개 후보를 검토했다.
핵심은 불확실성을 무한히 큰 금지 영역으로만 다루지 않고, 시간별 위험을 평가하며
짧은 실행 뒤 다시 계획하는 것이다. 아래 논문의 보장이나 실험 성능을 이 구현에
그대로 이전하지 않았다.

- [de Groot et al., Scenario-Based Trajectory Optimization, 2021](https://arxiv.org/abs/2103.12517)
- [Mustafa et al., Probabilistic Risk Assessment, 2023](https://arxiv.org/abs/2302.10846)
- [Bickel et al., 실제 궤도 먼지악마 이동 관측, 2025](https://doi.org/10.1126/sciadv.adw5170)
- [Battalio & Wang, 실제 폭풍 시계열과 배포 설명](https://battalio.com/mars-dust-activity-database/)
- [기존 MEDA·열관성·NOAH-H 근거와 v1 결과](HAZARD_RESEARCH_RESULTS.md)

Bickel 연구의 5개 HRSC 채널 시각별 이동은 후속 검증에 유용하지만, 이번 세션에서는
공개 연결 저장소의 다운로드를 확보하지 못했다. 해당 논문의 속도 통계를 독립적인
시계열 백테스트 정답으로 바꾸지 않았다. 실제 고빈도 위치·반경 시계열이 다음 핵심 자료다.
